# 🍔 React Food Delivery App

A modern Food Delivery web application built using React.js, Axios and Bootstrap with dynamic cuisine filtering functionality.

---

## 🚀 Features

- Dynamic food recipes display
- Cuisine based filtering system
- API integration using Axios
- Responsive Bootstrap design
- Reusable React components
- Dynamic rendering using props
- Real-time cuisine selection
- Scrollable recipe cards layout

---

## 🛠️ Technologies Used

- React.js
- JavaScript
- Bootstrap
- Axios

- CSS
